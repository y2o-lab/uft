## 実装

- エディタ・プレビューの ⌘/Ctrl+F、および検索ボタンから本文検索を開く。
- 日本語と英数字の文字列検索。大文字・小文字を区別せず、正規表現の記号は文字として扱う。
- 一致件数、全一致のハイライト、現在の一致の強調、該当箇所へのスクロール。
- Enter / Shift+Enter、↑↓ ボタンによる循環移動。Esc で閉じて本文へフォーカスを戻す。
- プレビューはインライン装飾をまたぐ表示テキストも検索できる。検索表示は本文の DOM や Markdown を変更しない。
- 本文編集時に一致を更新し、自動保存では検索窓と検索位置を保持。文書切り替え時は検索をリセット。

## CodeRabbit 指摘対応後の検証

PR #79 の4件の指摘を修正した。

- 検索窓を閉じた状態と空の検索語では、プレビューの全文走査・変更監視を停止する。検索開始時に再開する。
- 検索状態の識別にはワークスペース ID と文書 ID を使用し、同じパスの文書への切り替えも検知する。
- 入れ子のブロックの前後を別々の検索グループにし、一致を文書順に返す。
- プレビューツールバーの実際の高さに検索バーの固定位置を追従させ、PC・モバイルでの重なりを防ぐ。

回帰テストを追加し、`pnpm check`（エラー・警告0）、`pnpm lint`、`pnpm test`（100件）、`pnpm build`、`pnpm test:e2e --workers=2`（全62件）が成功した。画面確認は幅1280px・390pxで実施した。

## 追加レビュー（5688636766）への対応

エディタ検索にもワークスペース ID と文書 ID を組み合わせた `documentKey` を渡すよう修正した。同じ文書 ID を共有する旧形式の2ワークスペースを用意した回帰テストで、修正前は切り替え後も検索窓が残ることを再現し、修正後はエディタを再マウントせず検索状態がリセットされることを確認した。

`pnpm check`（エラー・警告0）、`pnpm lint`、`pnpm test`（100件）、`pnpm build`、検索のE2E（再現テストを含む8件）が成功した。

## 追加レビュー（5688765151）への対応

検索結果の更新とスクロール要求を分離した。エディタの本文更新とプレビューの DOM 更新では一致件数・強調表示だけを更新し、検索語の入力・Enter・前後ボタンの操作時だけ検索結果へスクロールする。一致が1件だけの場合も、明示的な移動操作では再びスクロールできる。

長文末尾での編集中に文書先頭へ移動する問題をエディタ・プレビュー双方で再現し、修正後は編集位置を保持することを回帰テストで確認した。検索語変更、前後移動、1件だけの一致への再移動も検証している。

`pnpm check`（エラー・警告0）、`pnpm lint`、`pnpm test`（100件）、`pnpm build`、`pnpm test:e2e --workers=2`（全65件）が成功した。
